Helium detects browser Apple Pay issues automatically. To turn off web billing issue detection, set the flag **before initializing Helium**:

<Accordion title="Turn off web billing issue detection">
  <Tabs>
    <Tab title="iOS">
      ```swift
      Helium.config.enableWebApplePayReadiness = false
      ```
    </Tab>
    <Tab title="Expo / React Native">
      ```tsx
      setEnableWebApplePayReadiness(false);
      ```

      React Native requires `@tryheliumai/paywall-sdk-react-native` 3.1.14+. On 3.1.13, set the native iOS flag in `AppDelegate` before JavaScript initializes Helium. This is a no-op on Android.
    </Tab>
    <Tab title="Flutter">
      ```dart
      await HeliumFlutter().setEnableWebApplePayReadiness(false);
      ```

      Requires `helium_flutter` 3.3.15+. On 3.3.14, set the native iOS flag in `AppDelegate` before Dart initializes Helium. This is a no-op on Android.
    </Tab>
  </Tabs>
</Accordion>
