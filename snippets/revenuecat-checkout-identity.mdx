**Using RevenueCat?** Either:

1. In Helium's **Paddle integration**, map our `rc_app_user_id` to the user ID field configured in your RevenueCat/Paddle integration (`rc_user_id` by default).
2. Set Helium's user ID to the RevenueCat anonymous ID before sign-in and the RevenueCat App User ID after sign-in. RevenueCat handles linking through `logIn()`.
