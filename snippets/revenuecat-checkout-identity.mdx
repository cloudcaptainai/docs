**Using RevenueCat?** Either:

1. In Helium's **Paddle integration** (when available), map the **RevenueCat App User ID** to the field RevenueCat uses to identify users (`rc_user_id` in the default setup).
2. Set Helium's user ID to RevenueCat's anonymous ID before sign-in, then its current App User ID after sign-in. RevenueCat links the account through `logIn()`.
